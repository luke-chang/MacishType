# runtime.js provenance

`runtime.js` is a byte-identical copy of
`MacishType/JavaScriptEngine/Resources/runtime.js` from the MacishType
repository (MIT), last touched there by commit
`613412c5112e9ad2006c42f93d5feb287ea43968`.

Do not edit it here. To pick up upstream changes, re-copy the file and update
the commit hash above. Host-specific behavior belongs in `hostglue.js`, which
defines the same host globals the macOS bridge registers natively.
